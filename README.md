# 名古屋・北陸 2027／3

> 目前版本 **v1.2**（2026-09-16）·「更新紀錄」見 [CHANGELOG.md](CHANGELOG.md)

2027 年 3 月名古屋與金澤團體旅行的機票、住宿與分攤整理。

- 分兩批出發，3/17 名古屋會合，3/23 同班機回台

- 機票各家自理，民宿統一收款

## 開發

純靜態，不需 npm 或建置工具，雙擊 `index.html` 即可預覽。
GitHub Pages 由 `main` 分支根目錄部署，推送後自動重建。

票價與住宿皆為現有估算，請以訂購時確認資訊為準。
